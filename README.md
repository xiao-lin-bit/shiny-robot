# 贪吃蛇 Snake‑Game
> 🐍 原生 HTML5 Canvas 实现的全屏穿墙贪吃蛇，**单文件零依赖**，浏览器直接打开即可游玩，适配电脑、手机、平板。

## ✨ 核心特性
- 🧱 **无边界穿墙机制**：蛇从屏幕边缘穿出会从对侧进入，只有咬到自身才会游戏结束，没有围墙限制
- 📐 **全屏自适应画布**：自动读取屏幕尺寸铺满窗口，窗口大小、设备旋转实时重绘；内置独立网格背景层
- ⚙️ **5档固定速度档位**（设置面板）
  - 1档慢 ~ 5档极速，默认3档标准速度
  - **速度完全固定，不会随得分/吃球数量自动变快**，配置本地持久化保存
- ⚡ **长按同向按键手动加速**
  - 需要按住与蛇前进方向**相同**的按键满 `0.3s` 充能后触发加速；反向按键无效果
  - 蛇头显示充能进度环，加速时有高亮+尾焰视觉反馈，松开按键立刻恢复原速
- 🟢 **限时绿色奖励球机制**
  - 连续吃掉5颗红球生成绿色高分球，存活时长8秒
  - 吃掉绿球获得额外分数，**蛇身体不会变长**；红绿球可共存，但位置永不重叠
  - 屏幕底部居中8格宽度进度条展示绿球剩余存活时间，无文字时间/百分比，倒计时结束自动消失
- 🎮 **双端操作支持**
  - PC键盘：`WASD` / 方向键转向，空格暂停，R重新开始
  - 移动端：屏幕滑动控制、屏幕虚拟方向按键；长按虚拟按键同样支持充能加速
- 💾 **本地存储**：自动保存最高分、速度档位配置，刷新页面不会丢失
- 📋 **内置设置面板&游戏说明**：打开设置自动暂停游戏，面板内完整展示全部游戏规则
- 📱 **移动端适配**：平板竖屏旋转提示，避开系统安全区，触屏体验优化

## 🎯 游戏规则
1. 吃掉红色果实：蛇身体变长，+1分，**不会改变基础移动速度**
2. 连续吃掉5颗红球，生成限时8秒绿色奖励球；超时自动消失
3. 吃掉绿色奖励球：+5分，蛇身体长度不变；红绿球不会重叠
4. 按住与蛇前进方向相同的按键，充能0.3秒后触发手动加速，松开恢复原速；反向按键无任何效果
5. 支持穿墙模式，仅咬到自己身体时游戏结束

## 🚀 快速开始
1. 下载项目内 `snake.html` 单个文件
2. 使用任意现代浏览器直接打开该HTML文件，立即开始游戏
3. 可直接部署静态网页服务，不需要编译、不需要第三方库
